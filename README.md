# Areeba Anwar — Portfolio

A cinematic, responsive portfolio concept for graphic designer Areeba Anwar.

## Start the website

1. Install Node.js 20 or newer.
2. Open this folder in a terminal.
3. Run `npm install` once.
4. Run `npm run dev`.
5. Open `http://localhost:3000` in a browser.

## Replace the sample projects

The three concept images live in `public/work`. Replace them with Areeba's final portfolio artwork using the same filenames, or update the project list near the top of `app/page.js`.

Contact links are placeholders and should be updated before publishing.
